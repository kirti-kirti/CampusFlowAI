# Campus Flow AI

An AI-powered smart campus management platform designed to streamline academic and administrative operations in educational institutions. Campus Flow AI integrates multiple campus services into a single centralized web application for students, faculty, and administrators.

---

## 🚀 Features

### 📌 Smart Attendance Management

* QR Code based attendance system
* Reduces manual attendance errors
* Helps prevent proxy attendance
* Real-time attendance tracking

### 🚌 Bus Tracking System

* Live bus tracking similar to ride tracking apps
* Route monitoring using map integration
* Real-time location updates
* Estimated arrival timing for students

### 🔔 Notification System

* Instant announcements and alerts
* Event notifications
* Assignment and exam reminders
* Department-wise communication

### 📅 Timetable Management

* Smart timetable scheduling
* Daily class updates
* Faculty and student timetable access
* Organized academic planning

### 👨‍🎓 Student Management

* Student profile management
* Academic information tracking
* Attendance and performance records

### 🤖 AI Integration

* AI-powered automation and management support
* Smart recommendations and analytics
* Enhanced user experience

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/kirti-kirti/CampusFlowAI.git
```

### 2️⃣ Backend Setup

```bash
cd campusflow-ai
mvn clean install
mvn spring-boot:run
```

### 3️⃣ Frontend Setup

```bash
cd react-frontend
npm install
npm start
```
